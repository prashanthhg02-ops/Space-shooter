# Starstrike

A small, dependency-free space shooter that runs in a modern web browser.

## Play

Open `index.html` in your browser, then select **Start Game** (or press **Enter**).

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | `W` `A` `S` `D` or arrow keys | Direction pad |
| Fire | `Space` | Fire button |
| Pause or resume | `P` | — |

## Gameplay

Destroy incoming ships, dodge their shots, and survive increasingly difficult
waves. Some enemies drop power-ups that temporarily give your ship a triple shot.
Your score and best score are shown beside the game; the best score is saved in
your browser.

Use the music-note button to toggle sound effects.

## Project files

- `index.html` — game page and HUD
- `style.css` — responsive layout and styling
- `game.js` — canvas rendering, controls, and game logic

No build step or package installation is required.
